Comment lire. À gauche, chaque flèche est une feature, telle que le modèle la range dans le plan à 2 dimensions. À droite, la diagonale (ambre) dit à quel point chaque feature est encodée ; le hors-diagonale dit comment elles se gênent — ambre = interférence positive, sarcelle = négative, celle que le ReLU rend gratuite. Coupez le ReLU : le modèle ne tolère plus aucune interférence et retombe sur deux features orthogonales, quelle que soit la sparsité.

Le Rendu 6 (en bas) rend l'interférence palpable. Activez une seule feature : son vecteur devient h dans le plan, puis le décodeur reconstruit le tout. Sur les features inactives apparaissent des barres pointillées — les fantômes d'interférence. ReLU activé, ils sont écrasés vers zéro (l'interférence négative est gratuite) ; coupez le ReLU et ils ressortent, positifs comme négatifs. Activez-en deux qui se gênent dans la heatmap : le fantôme grossit. C'est exactement pourquoi la superposition ne marche que si les features s'activent rarement ensemble.
